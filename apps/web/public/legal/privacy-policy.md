# 개인정보 처리방침

**시행일: 2026년 6월 1일 | 버전 1.0**

콘플로우(이하 "서비스")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 및 「인공지능 기본법」 등 관련 법령을 준수합니다. 본 개인정보 처리방침은 서비스가 수집하는 개인정보의 항목, 수집·이용 목적, 보유 기간 및 이용자의 권리에 대해 안내합니다.

---

## 제1조 (개인정보의 처리 목적)

서비스는 다음 목적을 위해 개인정보를 처리합니다.

1. **회원 관리**: 회원 가입, 본인 확인, 계정 관리, 서비스 부정 이용 방지
2. **서비스 제공**: 팀 협업, 스프린트 관리, 보드/백로그 관리, 실시간 메시지(DM), 허들(음성/영상 통화)
3. **AI 기반 서비스**: 회의 요약, 블로커 분석, 회고 인사이트 생성 (AI가 처리하며, 생성 결과에는 "AI 생성" 표시가 부착됩니다)
4. **서비스 개선**: 이용 통계 분석, 오류 탐지 및 해결

---

## 제2조 (수집하는 개인정보의 항목 및 수집 방법)

### 1. 수집 항목

| 구분                    | 항목                                                                            |
| ----------------------- | ------------------------------------------------------------------------------- |
| **필수 수집**           | 이름, 이메일 주소 (OAuth 인증 시 제공)                                          |
| **자동 수집**           | IP 주소, 접속 로그, 브라우저 종류 및 버전, 접속 일시                            |
| **서비스 이용 중 생성** | 팀/스프린트/보드 데이터, 채팅 메시지, 업로드 파일, 허들 녹화·녹음, AI 생성 요약 |

### 2. 수집 방법

- OAuth 인증(Google, GitHub 등)을 통한 자동 수집
- 서비스 이용 과정에서의 자동 생성 및 수집
- 이용자의 직접 입력 및 파일 업로드

---

## 제3조 (개인정보의 보유 및 이용 기간)

1. **회원 정보**: 회원 탈퇴 시까지 보유하며, 탈퇴 즉시 파기합니다.
2. **접속 기록**: 「통신비밀보호법」 제15조의2에 따라 1년간 보관 후 파기합니다.
3. **허들 녹화 데이터**: 생성일로부터 90일 보관 후 자동 삭제합니다. (이용자가 직접 삭제할 수도 있습니다)
4. **AI 처리 데이터**: AI 처리 완료 후 원본 전송 데이터는 즉시 삭제하며, 생성된 요약본만 서비스 내 보관합니다.

---

## 제4조 (개인정보의 제3자 제공)

서비스는 AI 기능 제공을 위해 다음과 같이 개인정보를 제3자에게 제공합니다.

| 제공받는 자         | 제공 목적                                  | 제공 항목                                                           | 보유 기간                               |
| ------------------- | ------------------------------------------ | ------------------------------------------------------------------- | --------------------------------------- |
| OpenAI, Inc. (미국) | 회의 요약, 블로커 분석, 회고 인사이트 생성 | 회의 녹취 텍스트, 팀 활동 데이터 (가능한 범위에서 비식별화 후 전송) | API 처리 완료 즉시 삭제 (학습에 미사용) |

※ 이용자는 제3자 제공에 대한 동의를 거부할 수 있으나, 이 경우 AI 기반 기능 이용이 제한됩니다.

---

서비스는 원활한 운영을 위해 다음과 같이 개인정보 처리를 위탁합니다.

| 수탁자               | 위탁 업무                |
| -------------------- | ------------------------ |
| Supabase Pte. Ltd.   | 회원 인증 서비스         |
| 클라우드 호스팅 업체 | 데이터 저장 및 서버 운영 |

---

## 제6조 (개인정보의 국외 이전)

서비스는 AI 기능 제공을 위해 개인정보를 국외로 이전합니다.

| 이전받는 자        | 이전 국가 | 이전 항목                        | 이전 방법                    | 보유 기간           |
| ------------------ | --------- | -------------------------------- | ---------------------------- | ------------------- |
| OpenAI, Inc.       | 미국      | 회의 녹취 텍스트 (비식별화 처리) | API 호출 (HTTPS 암호화 전송) | 처리 완료 즉시 삭제 |
| Supabase Pte. Ltd. | 싱가포르  | 인증 토큰, 이메일                | API 호출 (HTTPS 암호화 전송) | 계정 삭제 시까지    |

---

## 제7조 (개인정보의 파기 절차 및 방법)

1. **파기 절차**: 보유 기간이 경과하거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다.
2. **파기 방법**:
   - 데이터베이스(PostgreSQL) 기록: 완전 삭제
   - 벡터 임베딩(pgvector): 완전 삭제
   - 업로드 파일: 스토리지에서 완전 삭제
   - 백업 데이터: 다음 백업 주기 시 반영하여 삭제

---

## 제8조 (이용자의 권리 및 행사 방법)

이용자(또는 법정대리인)는 다음 권리를 행사할 수 있습니다.

1. 개인정보 열람 요구
2. 개인정보 정정·삭제 요구
3. 개인정보 처리 정지 요구
4. 동의 철회

**행사 방법**: 서비스 내 설정 페이지 또는 이메일(support@conflow.app)로 요청할 수 있으며, 지체 없이(10일 이내) 조치합니다.

---

## 제9조 (만 14세 미만 아동의 개인정보)

서비스는 만 14세 미만 아동의 회원가입을 받지 않으며, 만 14세 미만 아동의 개인정보를 수집하지 않습니다.

---

## 제10조 (개인정보의 안전성 확보 조치)

서비스는 다음과 같은 안전성 확보 조치를 취하고 있습니다.

1. **전송 구간 암호화**: HTTPS(TLS 1.2 이상)를 통한 데이터 전송
2. **저장 데이터 암호화**: 민감 정보의 데이터베이스 수준 암호화
3. **접근 권한 관리**: 최소 권한 원칙에 따른 접근 통제
4. **접속 기록 보관**: 1년간 접속 기록 보관 및 관리
5. **팀 데이터 격리**: 팀 간 데이터 접근 차단

---

## 제11조 (AI 서비스 이용 시 개인정보 처리 특칙)

1. 서비스의 AI 기능(회의 요약, 블로커 분석, 회고 인사이트)은 OpenAI의 API를 활용하여 처리됩니다.
2. AI 처리를 위해 전송되는 데이터는 가능한 범위에서 비식별화(이름 마스킹 등)하여 전송합니다.
3. OpenAI API를 통해 전송된 데이터는 AI 모델 학습에 사용되지 않습니다.
4. AI가 생성한 모든 콘텐츠에는 "AI 생성" 표시가 부착됩니다.

## 제14조 (방침 변경에 관한 사항)

본 개인정보 처리방침은 시행일로부터 적용되며, 변경 시 서비스 내 공지사항을 통해 7일 전 고지합니다. 중요한 변경 사항(수집 항목 추가, 제3자 제공 변경 등)은 30일 전 고지합니다.

- **공고일자**: 2026년 5월 27일
