# 경쟁 환경 분석

## 이 문서로 내릴 결정

1. 각 경쟁사에 대해 **공략 포인트와 회피 영역**이 무엇인가
2. 영업 현장에서 **"Conflow vs X"**가 나왔을 때 어떤 메시지로 답할 것인가
3. 어떤 통합·임포터를 **우선 만들 것인가** (마이그레이션 경로)

## 경쟁사 맵 (4분면)

```
                      도메인 통합도 높음
                              │
                              │
       Microsoft 365 ●        │       ● Conflow (목표 위치)
       Atlassian Suite ●      │
       (라이선스 통합)         │
                              │
   ───────────────────────────┼─────────────────────────── AI 깊이 높음
   가벼움/AI 약함              │              AI 깊고 자율 실행
                              │
       Slack ●                │       ● Notion AI
       Jira ●                 │       ● Linear (AI 부상중)
       Monday ●               │       ● ClickUp AI
       Asana ●                │
                              │
                      도메인 통합도 낮음
```

요점: 우측 상단(통합 × AI 깊이) 4분면이 비어있다. 이게 우리의 공략 위치다.

## 직접 경쟁사

### 1. Atlassian (Jira / Confluence / Trello)

**위치**: PM 시장 1위, 미드마켓·엔터프라이즈 표준.

**강점**

- 광범위한 마켓플레이스 (3,000+ 앱)
- 엔터프라이즈 신뢰도 (SOC2, FedRAMP)
- 기존 사용자 락인 (수년치 이슈 데이터)

**약점 (우리 공략점)**

- **개별 라이선스 4-5개를 사야 함**: Jira + Confluence + Jira Service + Atlas + Compass. SMB가 30명일 때 누적 비용 월 100만원 초과.
- **Atlassian Intelligence는 단일 제품 안에서만 작동**: Jira의 AI는 Jira 이슈만 본다. 도메인 횡단 불가.
- **UX 무거움**: 30명 회사가 도입하려면 컨설팅이 필요한 수준의 설정 부담.
- **HR/문서 도메인 부재**: 협업의 절반만 다룬다.

**우리 공략 메시지**

> "Atlassian은 미드마켓 200명부터 진가를 발휘하지만, 30-100명 구간에서 라이선스를 다 사야 효과가 나는 함정이 있습니다. Conflow는 같은 가격대에서 PM + HR + 문서까지 포함되고, AI는 이슈와 사람을 같이 봅니다."

**마이그레이션 임포터 우선순위**: Jira 이슈 임포트 = **Phase 1 필수**. Confluence 페이지 임포트 = Phase 2.

---

### 2. Linear

**위치**: SaaS 스타트업의 PM 표준. UX 벤치마크.

**강점**

- 압도적 UX (속도, 키보드 단축키, 그래픽)
- Cycles, Projects, Roadmap 깔끔한 추상화
- 개발자 NPS 매우 높음

**약점 (우리 공략점)**

- **단일 도메인 (PM만)**. Comms는 Slack 통합으로 외부 의존.
- **한국어 UX 부족 / 한국 결제 불편 / 한국 노무 0**.
- **AI는 이슈 작성 보조 수준**. 도메인 횡단 없음.
- **소프트웨어 팀 외 사용자에게 학습 곡선** — 디자이너, 운영, HR에는 직관적이지 않음.

**우리 공략 메시지**

> "엔지니어팀만 쓸 거면 Linear가 훌륭합니다. 회사 전체가 같이 쓸 거면 Linear의 PM UX + Slack의 대화 + Workday의 HR을 따로 사거나, Conflow로 통합하세요."

**마이그레이션 임포터 우선순위**: Linear API 기반 이슈 임포트 = **Phase 1 권장**. Linear 사용자가 우리의 가장 빠른 PLG 전환층.

---

### 3. Slack (Salesforce)

**위치**: 비즈니스 메신저 표준.

**강점**

- 네트워크 효과 (외부 워크스페이스 연결, Slack Connect)
- 압도적 생태계 (수만 개 통합)
- 미드마켓·엔터프라이즈에서 락인 강함

**약점 (우리 공략점)**

- **Slack Enterprise Grid 가격 매우 비쌈**: 200명+ 미드마켓에서 사용자당 월 $15 이상. 한국 SMB는 부담.
- **Slack AI는 채널 요약 수준**. 이슈/인사 데이터 모름.
- **PM/HR/문서 부재**: 다른 도구 통합 필수.
- **카카오워크/네이버웍스의 한국 점유율 위협**을 받고 있음 — 차세대 진입자 자리가 비어있음.

**우리 공략 메시지**

> "Slack은 메신저로는 최고지만, 메신저만으로는 회사가 안 돌아갑니다. Conflow Comms는 Slack 수준의 메시징 + Huddle을 제공하면서, 같은 워크스페이스의 이슈·인사 데이터를 AI가 같이 봅니다."

**마이그레이션 임포터 우선순위**: Slack 채널/메시지 임포트 = **Phase 2 필수**. Slack Connect 호환성 = Phase 3.

---

### 4. Notion

**위치**: 문서·DB 자체조립 시장의 강자.

**강점**

- 무한 유연성 (DB, 페이지, 뷰)
- Notion AI 통합 (검색, 작성)
- 한국 사용자 친숙도 매우 높음

**약점 (우리 공략점)**

- **PM/스프린트는 자체 조립**: 50명+ 회사에서 보드/스프린트 규율이 깨짐.
- **HR/문서발급 미지원**.
- **권한 모델 단순함** — 미드마켓 RBAC 요건 미충족.
- **느린 검색**, **버전 관리 약함**.

**우리 공략 메시지**

> "Notion은 문서로는 좋지만, 스프린트가 시작되면 보드/이슈/티켓은 따로 둬야 합니다. Conflow는 Notion 수준의 문서 작성 + Jira 수준의 이슈 관리를 같은 워크스페이스에 둡니다."

**마이그레이션 임포터 우선순위**: Notion 페이지 임포트 = **Phase 2 권장**. DB 마이그레이션은 매우 복잡 — Phase 3 검토.

---

### 5. Monday.com / ClickUp / Asana

**위치**: "올인원" 포지셔닝 SaaS. SMB-미드마켓 타깃.

**강점**

- 보드 기반 시각화
- 다양한 워크플로우 템플릿
- 영업 조직이 강함 (특히 Monday)

**약점 (우리 공략점)**

- **"올인원"이지만 사실은 보드 위에 모든 걸 욱여넣음** — HR/인사 평가가 보드처럼 보임.
- **AI는 자동화 룰 수준**: "이 컬럼이 바뀌면 알림" 정도. 자율 에이전트 없음.
- **한국 영업 인력 부족 / 한국 시장 우선순위 낮음**.
- **확장성**: 미드마켓 800+에서 ClickUp 성능 이슈 보고 다수.

**우리 공략 메시지**

> "Monday/ClickUp의 '뭐든지 보드'는 PM에서는 동작하지만 HR 평가나 1:1에서는 어색합니다. Conflow는 각 도메인에 맞는 데이터 모델과 UI를 가지면서도, 워크스페이스/권한/AI는 통합됩니다."

## HR 도메인 경쟁

### 6. Workday / Gusto / Rippling

**위치**: HR SaaS 글로벌 강자.

**강점**

- HR 깊이 (인사, 평가, 급여, 베네핏)
- 컴플라이언스 (미국 기준)

**약점 (우리 공략점)**

- **한국 4대 보험 / 근로기준법 미지원**. 글로벌 본사가 한국 자회사에 강제 도입하는 경우 외에는 안 쓰임.
- **PM/Comms 부재**.
- **가격 매우 비쌈**: Workday는 미드마켓 미만 거의 안 들어옴.

**우리 입장**: 직접 경쟁 아님. 다만 한국 자회사의 글로벌 본사가 Workday를 강제할 경우 우리는 PM/Comms 영역만 확보하고, HR은 양립.

### 7. Flex (한국)

**위치**: 한국 HR SaaS 시장 1위 (스타트업·SMB).

**강점**

- 4대 보험, 근로기준법 지원
- 한국 노무사 협업 워크플로우
- 한국 영업 강함

**약점 (우리 공략점)**

- **PM/Comms 부재** — 별도 Slack/Jira 필요
- **AI 기능 거의 없음**
- **문서발급은 기본만**: 전자서명/국세청 연동은 약함

**우리 공략 메시지**

> "Flex는 한국 노무에서는 신뢰할 만한 선택이지만, 인사 데이터가 PM과 Comms와 단절돼 있습니다. Conflow는 Flex 수준의 한국 노무 정확도를 PM/Comms와 동일 워크스페이스에 둡니다."

**전략**: Flex가 견고하므로 Phase 3에서 정면 대결하지 말고 **임포터로 흡수 + AI로 차별화**. 직접 우월성보다는 "통합 시 더 가치 있음" 메시지.

### 8. 시프티 (한국 근태 SaaS)

**위치**: 근태·스케줄링 특화.

**약점**: 도메인 좁음. 우리는 근태를 HR 도메인의 한 기능으로 흡수.

## 문서발급 도메인 경쟁

### 9. 모두싸인 / 도큐사인 (한국)

**위치**: 전자서명 SaaS.

**전략**: 직접 경쟁이 아니라 **API 통합**. Phase 4에서 자체 전자서명(KISA 인증) 구축이 어렵다면 모두싸인 어댑터로 시작.

### 10. 노무사 사무소 + 엑셀

**위치**: SMB의 60%+ 현실. 가장 큰 경쟁자는 "현상유지".

**공략 메시지**

> "노무사 비용은 그대로 두고, 노무사가 우리 워크스페이스에 외부 협업자로 들어와서 일하게 만듭니다. 엑셀 왕복이 사라집니다."

## 신규 진입 위협 (Watch List)

1. **Linear가 Comms로 확장**: Linear가 메신저를 붙이면 가장 위험. 모니터링 우선순위 최고.
2. **Notion이 HR 진입**: Notion AI가 인사 DB를 강화하면 위협. 한국 노무 미지원이 우리 방어선.
3. **카카오워크가 PM 강화**: 한국 점유율 + 카카오 생태계는 강력. 우리는 글로벌 수준 UX로 차별화.
4. **OpenAI / Anthropic의 워크스페이스 진입**: ChatGPT가 "회사용 워크스페이스"를 만들면 게임 체인저. 6-18개월 내 가능성 있음. → 우리는 **데이터 통합 우위**로 방어해야 함.
