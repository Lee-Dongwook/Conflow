# 포지셔닝

이 문서를 읽고 나면 다음 한 문장을 누구에게나 동일하게 말할 수 있어야 한다.

> "Conflow는 \_**\_를 위한 \_\_**인데, \_**\_와 달리 \_\_**한다."

## 정식 포지셔닝 스테이트먼트

> **30명에서 300명으로 성장 중인 한국 IT 회사의 운영 리더**를 위한 **AI 네이티브 통합 워크스페이스**입니다.
> Jira + Slack + Workday + 노무사 엑셀을 따로 사야 하는 **레거시 SaaS 스택**과 달리, Conflow는 **이슈 / 대화 / 인사 / 문서를 하나의 데이터·권한 모델 위에 두고**, AI가 도메인 경계를 넘어 일을 대신 처리합니다.

## 카테고리 전략: 우리가 어디에서 싸우는가

### 1순위 카테고리: "AI 네이티브 워크스페이스 (AI-native Workspace)"

이미 존재하는 카테고리에 들어간다. **새 카테고리를 만들지 않는다** — SMB는 카테고리 교육을 받을 시간이 없다.

- 기존 검색어: "Jira 대안", "Slack 대안", "Notion AI", "Linear 한국어"
- 우리 위치: 위 모든 검색어의 **공통 답**이 되는 것
- 비교 진열대: Linear, Monday, ClickUp, Notion, Asana, Wrike

### 카테고리 창조는 의도적으로 피한다

"통합 워크스페이스 OS" 같은 신조어는 만들지 않는다. Coda, Airtable, Tana가 시도하다 멈춘 함정이다. SMB는 자기가 산 게 무엇인지 30초에 설명 가능해야 한다.

## 차별화 4축

경쟁사 대비 우리가 **명백히 다르다고 입증 가능한** 4개 축. 한 줄 마케팅 카피가 아니라 제품 의사결정의 기준이다.

### 축 1. 도메인 통합도 (Domain Integration)

| 도구                                            | PM    | Comms | HR         | 문서발급 | 통합 깊이                       |
| ----------------------------------------------- | ----- | ----- | ---------- | -------- | ------------------------------- |
| Jira                                            | O     | X     | X          | X        | 단일 도메인                     |
| Slack                                           | X     | O     | X          | X        | 단일 도메인                     |
| Notion                                          | 부분  | X     | X          | X        | DB 기반 자체조립                |
| Monday                                          | O     | 부분  | 부분       | X        | 보드 기반 확장                  |
| ClickUp                                         | O     | 부분  | X          | X        | 보드 기반 확장                  |
| Atlassian (Jira+Confluence+Jira Service+Trello) | O     | X     | X          | X        | 별도 라이선스, SSO만 통합       |
| Microsoft Teams 365                             | O     | O     | 부분(Viva) | X        | 라이선스 별도, 데이터 별도      |
| **Conflow**                                     | **O** | **O** | **O**      | **O**    | **단일 데이터 모델, 단일 권한** |

요점: "다 한다"가 차별점이 아니다. **"하나의 데이터 모델 위에서 다 한다"**가 차별점이다. ClickUp이 다 하는 것처럼 보이지만, 보드를 인사 평가에 욱여넣은 형태에 가깝다.

### 축 2. AI의 작동 방식 (Where AI lives)

| 도구             | AI 위치                          | AI가 보는 데이터                |
| ---------------- | -------------------------------- | ------------------------------- |
| Jira             | "AI 어시스턴트" 사이드패널       | Jira 이슈만                     |
| Linear           | 이슈 생성 보조                   | Linear 이슈만                   |
| Notion AI        | 페이지 안                        | 해당 워크스페이스 페이지        |
| Slack AI         | 채널 요약                        | Slack 메시지만                  |
| Monday AI        | 자동화 룰                        | Monday 보드만                   |
| **Conflow A2UI** | **워크스페이스 자체가 에이전트** | **PM + Comms + HR + 문서 전체** |

요점: 경쟁사 AI는 **자기 도메인 안에서만** 작동한다. Conflow는 "지난 스프린트 블로커가 누구 때문에 발생했고, 그 사람이 1:1에서 어떤 피드백을 받았는지" 같은 **도메인 횡단 질문**에 답할 수 있다. 이건 데이터 모델 통합이 선행되어야만 가능하다 — 글루 코드로 위에 얹어서는 안 된다.

세부 설계는 `04-architecture/a2ui-strategy.md` 참고.

### 축 3. 한국 노무·세무 1순위 (KR-first Compliance)

| 도구               | 4대 보험 | 근로기준법 워크플로우 | 전자서명 (KISA 인증) | 국세청 ezTax    | 노무사 협업 |
| ------------------ | -------- | --------------------- | -------------------- | --------------- | ----------- |
| Workday            | X        | X                     | X                    | X               | X           |
| Gusto / Rippling   | X        | X                     | X                    | X               | X           |
| Flex (한국 SaaS)   | O        | O                     | 부분                 | 부분            | 부분        |
| 시프티 (한국 SaaS) | 부분     | O (근태 중심)         | X                    | X               | X           |
| **Conflow**        | **O**    | **O**                 | **O (Phase 4)**      | **O (Phase 4)** | **O**       |

요점: 글로벌 HR SaaS는 한국 법령을 모른다. 한국 HR SaaS는 PM/Comms가 없다. 우리는 **글로벌 SaaS 수준의 PM/Comms UX + 한국 HR SaaS 수준의 노무 정확도**를 같은 워크스페이스에 둔다.

상세 요건은 `02-product/domain-hr.md`, `02-product/domain-documents.md` 참고.

### 축 4. 마이그레이션 비용 (Switching Cost: 우리에게 → 우리에게)

| 시점             | 일반 SMB가 겪는 일              | Conflow 사용자가 겪는 일  |
| ---------------- | ------------------------------- | ------------------------- |
| 30명 → 80명      | Notion → Jira 마이그레이션      | 동일 워크스페이스 유지    |
| 80명 → 200명     | HR 툴 신규 도입                 | HR 도메인 활성화 (스위치) |
| 200명 → 미드마켓 | Slack Enterprise Grid 재이전    | SCIM/SSO 활성화 (스위치)  |
| 임직원 50명 추가 | 라이선스 다중 결제, 권한 재구성 | 워크스페이스 시트만 추가  |

이건 마케팅이 아니라 **데이터 모델 결정**이다. `04-architecture/data-model.md`의 Workspace = 단일 테넌트 원칙이 깨지면 이 차별점이 같이 깨진다.

## 포지셔닝 캔버스

```
타깃 고객 (Target Customer)
  Primary:   30-200명 한국 IT 회사의 COO / Head of Ops / People Ops 리더
  Secondary: 시리즈 A-B 스타트업 CTO (PM 도메인 진입), 미드마켓 IT 운영팀 (Phase 3+)

시장 카테고리 (Market Category)
  Primary:        AI 네이티브 통합 워크스페이스
  카테고리 위치:   Linear / Monday / ClickUp 옆 자리. Notion보다 PM·HR·문서 강함, Workday보다 UX 가벼움.

핵심 가치 제안 (Unique Value Proposition)
  핵심 혜택:   "성장하는 회사가 협업 스택을 다시 사지 않아도 됨"
  증명 포인트:
    1. 4개 도메인이 하나의 데이터/권한 모델 위에서 동작
    2. AI가 도메인 경계를 넘어 작업 수행 (A2UI)
    3. 한국 노무·세무 시스템과 1급으로 연동 (Flex/시프티 수준)
    4. 50명 가격에서 SOC2/K-ISMS 수준 보안 제공

경쟁 대안 (Competitive Alternatives)
  현상 유지:    Notion + 카카오워크 + 엑셀
  직접 경쟁:    Jira+Slack+Workday 묶음 / Monday / ClickUp
  간접 경쟁:    Atlassian 스택 / Microsoft 365 / 카카오워크 + Flex
  대체재 위협:  Linear + Slack 조합 (가볍지만 통합 부재)
```

## 포지셔닝 카피 (사용처별)

### 한 문장 (홈페이지 hero)

**"이슈, 대화, 인사, 문서 — 하나의 워크스페이스. 하나의 AI."**

### 두 문장 (영업 콜드메일)

**"Jira + Slack + Workday를 따로 사신다면, 데이터가 따로 살아 AI가 회사 전체를 이해하지 못합니다. Conflow는 4개 도메인을 하나의 데이터 모델에 두고, AI가 도메인을 넘나들며 실제로 일을 처리합니다."**

### 30초 (투자자 / 영업 미팅)

> "한국에서 30명에서 300명으로 성장 중인 회사는 협업 스택을 평균 3번 갈아엎습니다. Slack에서 Slack Enterprise로, Notion에서 Jira로, 노무사 엑셀에서 Flex로. 매번 데이터, 권한, 통합을 재구성합니다.
>
> Conflow는 그 4번의 전환점을 하나의 워크스페이스로 흡수합니다. PM, Comms, HR, 문서가 같은 데이터 모델 위에 있어, 50명에서 500명까지 동일한 도구로 자랍니다. 그리고 우리 AI는 도메인 경계 없이 작동합니다 — "지난 스프린트 블로커가 누구이고, 그 멤버의 1:1 피드백은 무엇인지"를 한 번에 답할 수 있는 유일한 협업 툴입니다.
>
> 한국 시장 진지하게 다룹니다. 4대 보험, 전자서명, 국세청 연동을 1순위로 봅니다."

## 안티-포지셔닝 (우리가 절대 쓰지 않을 문구)

다음 문구는 차별성이 없거나, 약속을 못 지킬 위험이 크다.

- "All-in-one 협업 툴" — 모든 도구가 이렇게 말한다. 의미 없음.
- "AI가 모든 걸 자동화" — 과약속이다. A2UI 범위를 정확히 말해야 한다.
- "Jira보다 빠르다" — 입증 책임이 크다. 차별 축으로 쓰지 말 것.
- "한국형 협업 툴" — 우리는 한국에서 시작하지만 글로벌 UX 수준을 유지한다. "한국형"은 진입장벽 낮은 도구로 오해된다.
- "쉽다 / 직관적이다" — 모든 SaaS가 이렇게 말한다. 차별점 아님.

## 포지셔닝이 깨지는 조건 (Watch List)

다음 신호가 보이면 포지셔닝을 재검토한다.

1. **고객이 "Conflow는 Jira 같은 거죠?"라고 30초 안에 정정 못 받음** → 통합 차별점 전달 실패
2. **AI 기능 데모에서 단일 도메인만 보여주게 됨** → A2UI 약속이 마케팅뿐
3. **HR/문서 도메인이 Phase 3-4에서 슬립** → 한국 노무 1순위 약속 깨짐
4. **신규 고객 ACV가 미드마켓으로 못 올라감 (계속 SMB만)** → "성장하는 회사" 약속 깨짐, 확장 비용 0 가설 검증 실패
