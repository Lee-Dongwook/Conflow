# 5년 제품 비전 (2026-2031)

이 문서는 [positioning.md](./positioning.md)를 **시간축**으로 풀어낸 것이다.
포지셔닝이 "어디에서 싸우는가"를 답한다면, 이 문서는 **"언제 무엇을 만들고, 언제 무엇을 미루는가"**를 답한다.

## 이 문서로 내릴 결정

1. **5년 뒤 Conflow의 모습**을 경영진/투자자/팀이 동일하게 그릴 수 있게 한다
2. **매 Phase에서 무엇을 빌드하고 무엇을 미루는가** — 스코프 절제의 기준
3. **비전을 재검토해야 하는 신호**가 어떤 것인지 사전 정의

> 이 문서는 로드맵이 아니다. 분기 단위 우선순위는 `03-roadmap/phases.md`, `03-roadmap/moscow.md`에서 다룬다. 이 문서는 그 위의 **방향 합의**다.

## 5년 후 모습 (2031년) — North Star

> **2031년, 한국에서 30명에서 1,000명으로 성장하는 IT 회사의 운영 리더가 "협업 도구"라고 하면 Conflow를 떠올린다.**
> 한국 IT SMB(30-200명) 시장에서 **유료 워크스페이스 점유율 12-18%** (≈ 1,500개 워크스페이스, ACV 평균 4,000만원), 미드마켓(200-2000명)에서는 **신규 도입 회사 중 30% 이상이 비교 대상에 Conflow를 포함**시킨다.
> 글로벌 확장은 일본·동남아 한국계 법인에 한정해 시작했고, 영미권 직접 진출은 보류 상태다. 이 숫자에 도달하지 못할 확률을 30-40% 수준으로 본다 — 도달 못 했을 때의 의미는 "한국 노무·세무 약속을 완성하지 못했거나, A2UI가 데모 수준에 머물렀다"일 가능성이 가장 크다.

이 숫자의 근거 한 줄: 한국 IT SMB(30-200명) 약 8,000-12,000개사 추정(스타트업얼라이언스/중기부 데이터 외삽), 그 중 PM+Comms+HR을 통합 도구로 옮길 의향이 있는 비율을 보수적으로 15-20%로 가정.

세부 사용자 시나리오 — "2031년, 80명 한국 SaaS 스타트업의 COO":

- 월요일 9시: Conflow 워크스페이스에 출근. **하나의 화면**에서 지난주 스프린트 결과 / 이번주 1:1 일정 / 신규 입사자 입사 절차 진행률 / 노무사가 검토 대기 중인 문서를 본다.
- AI 에이전트가 "지난 스프린트에서 가장 자주 블로커가 된 멤버는 누구이고, 그 멤버의 최근 1:1 피드백은 어떤 키워드를 포함하나"를 자동 요약.
- 신규 입사자가 들어와도 Slack / Jira / Notion / Flex 계정을 따로 만들지 않는다. **Conflow 시트 1개**만 추가.
- COO는 Jira / Slack / Workday / 노무사 엑셀이 한 회사에서 쓰이던 시절을 기억하지 못한다.

이 시나리오가 안 그려진다면 비전이 흐려진 것이다.

### Phase 0 — 검증 (2026 H2)

**ICP**: ICP-1 가설 대상 (실제 고객 아님)

**빌드 목표**

- [icp.md](../01-market/icp.md) ICP 가설 검증 인터뷰 5건
- 알파 워크스페이스: PM 핵심(이슈, 보드, 스프린트) + Comms 골격(채널, DM)만. 5-10개사 알파 동의.
- 데이터 모델 v1 확정 — Phase 1-4 내내 안 깨질 단일 워크스페이스 / 단일 권한 모델. `04-architecture/data-model.md`에서 상세.

**안 빌드하는 것**

- 결제, 가격 페이지, 영업 자료
- HR / 문서 도메인 (스키마 초안만, UI 없음)
- AI 기능 (A2UI는 데이터 모델 안정 후)
- 모바일 (웹 우선)

**종료 조건**

- ICP-1 인터뷰 5명 중 4명이 "이 문제 있다, 30일 안에 검토하겠다"
- 알파 워크스페이스 3개가 주 3회 이상 활성 사용
- 미달 시 → Phase 1 진입 보류, ICP 재정의

### Phase 1 — Beachhead (2027 H1)

**ICP**: ICP-1 (30-80명 한국 IT 회사)

**빌드 목표**

- **PM 도메인 정식 출시**: Linear 수준 UX 벤치마크. 키보드 단축키, 속도가 차별점 1번.
- **Comms 도메인 기본**: 채널, DM, 멘션, 검색. Huddle은 Phase 2.
- **임포터 2개**: Jira 이슈 임포트, Linear 이슈 임포트. [competitive-landscape.md](./competitive-landscape.md)의 우선순위 따름.
- **결제 + PLG 온보딩**: Free → Team → Business 3-tier (가격은 `01-market/pricing-strategy.md`).
- **기본 보안**: SSO (Google/Microsoft), 감사로그 기초, 보안 백서.

**안 빌드하는 것**

- HR / 문서 도메인 (Phase 2-3로 미룸)
- A2UI (Phase 2 — 데이터 양이 부족함)
- 미드마켓 보안 (SOC2 Type II, SCIM은 Phase 3)
- Slack 임포트 (Phase 2 — Slack은 마이그레이션 압력이 크지 않음)
- 모바일 풀 기능 (읽기 전용 모바일까지만)

**종료 조건**

- 유료 워크스페이스 100개 (ICP-1 기준)
- 신규 가입 → 유료 전환율 20%+
- 사용자 NPS 30+
- 미달 시 → Phase 2 진입 전 PMF 점검

### Phase 2 — 통합 (2027 H2 – 2028 H1)

**ICP**: ICP-1 유지 + ICP-2 자생 확장

**빌드 목표**

- **A2UI 첫 출시** — 도메인 횡단 AI의 **외부 공개 데모**. [positioning.md](./positioning.md) 차별화 축 2의 핵심.
  - 출시 범위: PM ↔ Comms 횡단 (예: "지난 스프린트 블로커 토론 요약 + 액션 아이템 자동 생성")
  - HR ↔ PM 횡단은 Phase 3 (HR 데이터가 정식이 되어야 함)
- **HR 도메인 알파**: 인사 DB, 입퇴사 워크플로우, 1:1 기록. 한국 4대 보험 연동은 Phase 3.
- **임포터 추가**: Slack 채널/메시지, Notion 페이지.
- **Huddle (음성/화면공유)**: Comms 도메인 보강.
- **모바일 정식 출시** (iOS/Android).

**안 빌드하는 것**

- 한국 노무사 협업 워크플로우 (Phase 3 — HR이 정식이 된 다음)
- 전자서명 / 국세청 연동 (Phase 4)
- 미드마켓 보안 인증 (SOC2 Type II는 Phase 3)
- 비IT 산업 템플릿

**종료 조건**

- A2UI 도메인 횡단 데모를 외부 5개사 PoC에서 검증 통과 (정성 평가 + 사용 로그)
- HR 알파 워크스페이스 30개 활성 사용
- ICP-1 워크스페이스의 ICP-2로 자생 확장률 30%+ ([icp.md](../01-market/icp.md) "자생 경로" 가설 검증)
- 미달 (특히 A2UI 검증 미달) → 비전 재검토. Watch List 참조.

### Phase 3 — 미드마켓 진입 (2028 H2 – 2029 H1)

**ICP**: ICP-2 주력 + ICP-3 진입

**빌드 목표**

- **HR 도메인 정식**: 한국 4대 보험, 근로기준법 워크플로우, 노무사 협업(외부 협업자 권한 모델), 인사평가, 급여 골격. Flex 수준 정확도 목표.
- **미드마켓 보안**: **SOC2 Type II 인증** (필수), SSO/SAML 정식, **SCIM**, DLP 정책 골격, 감사로그 미드마켓 수준.
- **권한 모델 v2**: RBAC 세분화, 외부 협업자(노무사, 외부 컨설턴트), 워크스페이스 간 데이터 격리.
- **A2UI 확장**: HR ↔ PM ↔ Comms 3도메인 횡단. (예: "이 멤버의 스프린트 기여도 + 1:1 피드백 + 인사평가 정합성")
- **영업 조직**: SDR + AE 채용. SLG 채널 가동. PLG와 50:50.

**안 빌드하는 것**

- KISA 전자서명 자체 구축 (Phase 4 — 모두싸인 어댑터로 우회)
- 국세청 ezTax (Phase 4)
- K-ISMS 인증 (Phase 4)
- 글로벌 진출 / 다국어 (다국어 UI는 영문만 준비, 영업은 한국)
- 비IT 산업

**종료 조건**

- 미드마켓(200명+) 워크스페이스 20개 이상, 평균 ACV 5,000만원+
- SOC2 Type II 인증 완료
- HR 도메인 정식 워크스페이스의 30%+가 노무사 외부 협업 사용
- 미달 시 → 미드마켓 진입 시점 6-12개월 지연. ICP-2 강화에 자원 재배치.

### Phase 4 — 한국 노무·세무 완성 (2029 H2 – 2030)

**ICP**: ICP-3 + 한국 본사 미드마켓 정식

**빌드 목표**

- **KISA 인증 전자서명**: 자체 구축 vs. 외주(모두싸인 OEM) 결정은 Phase 3 종료 시점에 재검토. 자체 구축은 12-18개월, 비용 큼.
- **국세청 ezTax 연동**: 원천세, 4대 보험, 연말정산 자동화.
- **K-ISMS 인증**: 한국 미드마켓·공공 진입의 진입표.
- **HR 깊이 강화**: 평가 사이클, 보상, 베네핏, 휴가 정책.
- **AI 깊이 강화**: A2UI 4도메인(PM/Comms/HR/문서) 완전 횡단. "회사 운영 한 화면" North Star 시나리오 달성.
- **글로벌 알파**: 일본 / 동남아 한국계 법인 5-10개 대상 알파. **영미권은 보류**.

**안 빌드하는 것**

- 영미권 직접 진출 (2031+ 검토)
- 비IT 산업 (제조, 유통, 식음료 — 워크플로우 학습 비용 큼)
- 공공기관 / 금융 (조달 사이클, 망 분리 — [icp.md](../01-market/icp.md) 비-ICP)
- 새 도메인 (5번째 도메인 확장 금지 — 4도메인 깊이 우선)

**종료 조건**

- [positioning.md](./positioning.md) 차별화 축 3 (KR-first 컴플라이언스) 표에서 4대 보험 / 근로기준법 / KISA / ezTax / 노무사 협업 모두 "O"
- 미드마켓 ACV 평균 1억원+
- 한국 IT SMB 유료 워크스페이스 1,500개+ 진입

## 5년 동안 절대 안 바꾸는 것 (불변 원칙)

이 5가지가 차별화의 뿌리다. 이 중 하나라도 깨지면 [positioning.md](./positioning.md)의 차별화 4축도 함께 깨진다.

### 1. 단일 데이터 모델 (4 도메인 통합)

PM / Comms / HR / 문서가 **하나의 데이터베이스 스키마** 위에 있다. 별도 제품을 SSO로 묶는 것이 아니다.

- 깨지는 지점: 인수합병으로 별도 제품을 붙이는 결정. Phase 3 이후 유혹 강함.
- 깨지면 → 차별화 축 1 (도메인 통합도) 실패. ClickUp/Monday와 같아진다.

### 2. 단일 권한 모델 (Workspace = 단일 테넌트)

한 워크스페이스 안에서 권한, 시트, 청구가 **하나로 묶임**. 임직원 50명 추가 시 도메인별 라이선스 재구성 없음.

- 깨지는 지점: 미드마켓이 "HR만 별도 청구하고 싶다"고 요구할 때.
- 깨지면 → 차별화 축 4 (마이그레이션 비용 0) 실패. ICP-1 → ICP-3 자생 확장 가설 깨짐.

### 3. A2UI 우선 (모든 기능은 헤드리스부터)

모든 기능은 React 컴포넌트가 아니라 **헤드리스 비즈니스 로직**으로 먼저 정의된다. AI 에이전트가 도메인 경계를 넘어 호출 가능한 형태로. (CLAUDE.md "Headless logic" 규칙과 정렬, `04-architecture/a2ui-strategy.md` 참고)

- 깨지는 지점: 영업이 요구하는 단발성 UI 기능을 헤드리스 우회 없이 UI에 박는 결정.
- 깨지면 → 차별화 축 2 (도메인 횡단 AI) 점진 무력화.

### 4. 한국 노무·세무 1순위

글로벌 진출보다 **한국 본사 미드마켓 진입**을 먼저 완성한다. Phase 4까지 영미권 직접 진출 없음.

- 깨지는 지점: 투자 라운드에서 "글로벌 TAM이 더 크니 영어부터" 압력.
- 깨지면 → 차별화 축 3 (KR-first 컴플라이언스) 실패. Flex/시프티 대비 차별점 사라짐.

### 5. 글로벌 SaaS 수준 UX (Linear 벤치마크)

한국 SaaS의 "기능은 많고 UX는 느린" 패턴을 따라가지 않는다. PM 도메인은 Linear, Comms는 Slack, HR은 Workday의 UX 기준선을 넘는다.

- 깨지는 지점: 기능 출시 압박에 UX 세부를 미루는 결정 누적.
- 깨지면 → ICP-1의 "사용자" 페르소나(엔지니어/디자이너)가 이탈. 챔피언 도입 결정도 무력화. ([icp.md](../01-market/icp.md) 페르소나 절 참고)

## 5년 안에 바꿀 수 있는 것 (변동 영역)

불변이 아닌 것은 데이터로 결정한다. 신호가 보이면 분기 GTM 리뷰에서 변경.

## 안 하는 것 (Anti-Vision)

5년 동안 우리가 **명시적으로 안 하는** 것. [positioning.md](./positioning.md) 안티-포지셔닝의 비전 버전.

- **카테고리 창조 ("통합 워크스페이스 OS" 같은 신조어)** — Coda/Airtable/Tana 함정
- **5번째 도메인 확장 (예: CRM, BI, 마케팅 자동화)** — 4도메인 깊이 우선
- **2030년 이전 영미권 직접 진출** — 한국 노무·세무 완성 전에는 의미 없음
- **공공기관 / 금융 (망분리 시장)** — [icp.md](../01-market/icp.md) 비-ICP
- **온프레미스 / 프라이빗 클라우드 제공** — 미드마켓이 요구해도 거절 (단일 데이터 모델 운영 비용 폭증)
- **비IT 산업 진입 (Phase 4까지)** — IT 워크플로우 깊이가 우리의 우위
