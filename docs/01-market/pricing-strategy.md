# 가격 전략 (Pricing Strategy)

> 이 문서는 [positioning.md](../00-vision/positioning.md)의 차별화 4축과 [product-vision.md](../00-vision/product-vision.md)의 Phase 0→4 매출 모델을, [icp.md](./icp.md) ICP-1/2/3의 결제 행동에 맞춰 **숫자로 박는** 결정 문서다.
> 일반론(PLG가 뭔지, SaaS 가격 모델 분류)은 다루지 않는다.

---

## 이 문서로 내릴 결정

1. **4-Tier 가격 숫자 (KRW, 부가세 별도)**: Free 0원 · Team 시트당 월 12,000원(연 10,000원) · Business 22,000원(연 18,000원) · Enterprise 시트당 월 35,000원~(연계약 협상). 모두 부가세 별도.
2. **PLG → SLG 전환 시점**: Phase 1-2는 PLG 100%. Phase 3 진입과 동시에 Enterprise Tier 영업 견적 시작(PLG:SLG = 50:50). 그 전에는 Enterprise 가격을 공개하지 않는다.
3. **차별화를 깨는 가격 실수 (불변선)**: ① 도메인별 분리 가격 ② "AI 무제한" 약속 ③ 한국 결제 수단(카드/세금계산서/연 청구서) 누락 ④ 미드마켓 시트 가격이 Slack Enterprise Grid 초과 — 이 4개는 어떤 영업 압력에도 양보 금지.
4. **가격 모델 재검토 트리거**: Free → 유료 전환율 < 10%, Business 미드 이탈 > 20%, 미드마켓 ACV 6개월 누적 < 3,000만원 — 셋 중 하나 발견 시 분기 GTM 리뷰에서 모델 자체 재검토.
5. **확정 못한 숫자**: AI/A2UI 도메인 횡단의 over-cap 단가, Enterprise floor 정확 금액, 한국 노무·세무 기능의 Phase 4 가격 프리미엄 — 모두 "가설 v1". 검증 책임은 [`03-roadmap/metrics.md`](../03-roadmap/metrics.md).

## 가격 철학 (Pricing Principles)

각 원칙은 **차별화 4축 중 하나를 보호**한다. 원칙이 깨지면 포지셔닝이 같이 깨진다.

### 원칙 1. 도메인 통합 가격 (Per-seat, not per-domain)

가격은 **시트 × Tier**로만 매겨진다. "HR만 별도", "문서 모듈만 별도" 같은 도메인별 가격은 금지.

- 왜 원칙인가: [jtbd.md](./jtbd.md) Big Job #2 "회사가 커져도 도구를 안 갈아엎기"의 가격 측 표현. 도메인별 분리 가격은 [positioning.md](../00-vision/positioning.md) 차별화 축 4를 즉시 깬다.

### 원칙 2. Land에서 단순, Expand에서 깊이로 수익화

Free/Team은 **3가지 이하 변수**(시트 수, 결제 주기, Tier)로 의사결정. Business/Enterprise에서 깊이(보안, 한국 노무, A2UI 횡단)로 ARPU를 끌어올린다.

- 왜 원칙인가: ICP-1 정수영 COO는 30분 안에 결재 신청서를 받아야 한다(icp.md CEO-3). 가격이 복잡하면 PLG 깔때기가 막힌다.

### 원칙 3. Free Tier는 ICP-1 평가에 작동해야 함

Free는 **10시트까지** 무료. 단, Phase 1 종료 조건(유료 워크스페이스 100개)을 위협할 만큼 관대하지 않다.

- 왜 원칙인가: ICP-1 자격 기준에 "직원당 월 1.5만원 이상 SaaS 지불 의향"이 있다(icp.md). Free가 30명까지 무료면 ICP-1이 결제 안 한다.

### 원칙 4. 한국 노무·세무 기능은 Business 이상

한국 4대 보험 워크플로우, 노무사 외부 협업자 모드, 한국 세무 연동은 **Business 이상에서만 제공**. Enterprise에서만 풀 깊이.

- 왜 원칙인가: 차별화 축 3 (KR-first 컴플라이언스)는 우리의 가격 프리미엄 근거다. Team에서 무료로 풀면 Phase 4 ACV 1억원+ 목표(product-vision.md)가 무너진다.

### 원칙 5. AI/A2UI는 Tier로 차등, 도메인 횡단은 Business+

Free/Team은 단일 도메인 AI까지. **A2UI 도메인 횡단은 Business 이상에서만**. Enterprise는 자체 호스팅 옵션(vLLM, 한국 리전).

- 왜 원칙인가: 차별화 축 2(도메인 횡단 AI)는 마진이 가장 큰 차별점이다. 이걸 Team 가격에 끼우면 LLM 비용이 마진을 갉아먹는다.

### 원칙 6. 한국 결제 수단 풀 지원

카드 정기결제 / 세금계산서 / 연 청구서 / 부가세 처리를 **Phase 1부터 모두 지원**. 어느 하나도 누락 금지.

- 왜 원칙인가: icp.md ICP-1은 카드 or 세금계산서, ICP-3은 연 청구서다. 결제 수단 누락은 "영업 좌초"를 의미한다(jtbd.md COO-6).

### 원칙 7. Enterprise 가격은 비공개 (Floor만 시그널)

Enterprise는 공개 가격표에 "Custom"으로만 표기. 영업 견적에서 floor(시트당 월 35,000원)는 내부 기준선이지 공개 가격이 아니다.

- 왜 원칙인가: ICP-3은 연 계약 협상 시장이다(icp.md). 가격 공개는 협상력 상실 + 경쟁사 가격 매칭을 부른다.

## 4-Tier 구조

가격은 **시트당 월 KRW, 부가세 별도**. 모든 가격은 가설 v1.

### Tier 1: Free

| 차원 | 정의 |
| --- | --- |
| 누구 (Who) | 평가 단계 워크스페이스 / 5-15명 초소형 팀 (비-ICP지만 PLG 입구) |
| 가격 | **0원** |
| 시트 한도 | 10명까지 (11번째 시트 추가 시 Team 업그레이드 강제) |
| 포함 도메인 | PM 기본 + Comms 기본 (채널, DM, 검색). HR / 문서 도메인은 잠금. |
| AI/A2UI 한도 | 월 50메시지 / 워크스페이스 전체. 단일 도메인만. A2UI 횡단 불가. |
| 통합/임포터 | Linear 임포트만 (가벼운 land용). Jira/Slack/Notion 임포터는 Team+. |
| 보안 | SSO (Google/Microsoft) 무료 제공 — IT 블로커(icp.md IT-1) 우회 위해 의도적 무료. 감사로그는 Team+. |
| 결제 방식 | 결제 불필요 |
| 지원 | 셀프서비스 (문서 + 커뮤니티) |
| 마진 가정 | LLM 비용 부담만. 워크스페이스당 월 LLM 원가 < 3,000원 유지가 운영 한계. |

**가격 근거**: 30시트까지 무료로 풀면 ICP-1 자격 기준 "직원당 월 1.5만원 지불 의향"이 검증 안 됨. 10시트는 ICP-1(30-80명) 진입 전 평가 구간으로 충분.

### Tier 2: Team

| 차원 | 정의 |
| --- | --- |
| 누구 (Who) | **ICP-1 (30-80명 한국 IT 회사)** |
| 가격 | **시트당 월 12,000원** (월 결제) / **시트당 월 10,000원** (연 결제, 약 17% 할인) |
| 시트 한도 | 권장 10-80시트. 81+ 시트도 가능하나 Business 권장. |
| 포함 도메인 | **PM 풀 기능 + Comms 풀 기능** (Huddle은 Phase 2 이후 포함). HR/문서 미포함. |
| AI/A2UI 한도 | 시트당 월 500메시지. 단일 도메인 AI만 (예: PM 내부 요약, Comms 내부 요약). **A2UI 도메인 횡단 불가**. |
| 통합/임포터 | Jira / Linear / Slack / Notion 임포터 모두. Webhook, REST API 기본. |
| 보안 | SSO (Google/Microsoft/SAML 기본), 감사로그 90일, 데이터 export, 보안 백서 제공. SCIM은 Business+. |
| 결제 방식 | **카드 정기결제 + 세금계산서** (한국 SMB 표준). 부가세 별도. |
| 지원 | 이메일 지원 (영업일 24시간 응답 목표) |
| 마진 가정 | 매출총이익률 목표 **70%+**. LLM 비용 시트당 월 < 2,000원. |

**가격 근거**: icp.md COO 페르소나의 "현재 직원당 월 7-12만원 SaaS 비용 누적" 대비 Conflow Team은 **시트당 1.2만원으로 단일 도구 대체**. Jira+Slack+Flex 묶음(직원당 월 25만원, jtbd.md Trigger 1) 대비 **약 1/20 가격**. 한국 SaaS 시세(카카오워크 5,000-9,900원, Flex 7,000-15,000원 구간) 중간대 + PM/Comms 통합 프리미엄.

### Tier 3: Business

| 차원 | 정의 |
| --- | --- |
| 누구 (Who) | **ICP-1 성숙 (60-80명 시점) + ICP-2 (80-200명 SMB)** |
| 가격 | **시트당 월 22,000원** (월 결제) / **시트당 월 18,000원** (연 결제, 약 18% 할인) |
| 시트 한도 | 권장 50-300시트. |
| 포함 도메인 | PM + Comms + **HR 도메인** (인사 DB, 입퇴사 워크플로우, 1:1 노트, 휴가/근태 — Phase 2 알파 / Phase 3 정식) + **문서 도메인** (노무 검토 워크플로우, 문서 발급 기본). |
| AI/A2UI 한도 | **A2UI 도메인 횡단 가능** (시트당 월 무제한 사용, 워크스페이스 cap 적용). 차별화 축 2의 정가 제공 구간. |
| 통합/임포터 | Team 전체 + Confluence 임포트, Webhook 고급, A2UI SDK 베타. |
| 보안 | SSO/SAML 정식, **SCIM 자동 프로비저닝**, 감사로그 1년, DLP 정책 기본, SOC2 Type II 자료 제공 (Phase 3+), 노무사 외부 협업자 권한 모드. |
| 결제 방식 | 카드 / 세금계산서 / **연 청구서 옵션**. 부가세 별도. |
| 지원 | 이메일 + Slack 채널 공유. 분기 비즈니스 리뷰 (50시트+). |
| 마진 가정 | 매출총이익률 목표 **65%+**. A2UI LLM 비용 시트당 월 < 4,000원 (cap 관리). |

**가격 근거**: ICP-2 자격 기준은 "이미 Jira+Slack+Flex를 쓰는 회사" (icp.md). 그들의 직원당 월 비용 ≈ 25만원. Business 2.2만원은 **약 1/10 가격**으로 동일 기능 + 도메인 횡단 AI. Atlassian SMB 30명에서 라이선스 4개 누적 월 100만원+(competitive-landscape.md) 대비 Business 30시트 = 월 66만원 (연결제 시 54만원).

### Tier 4: Enterprise

| 차원 | 정의 |
| --- | --- |
| 누구 (Who) | **ICP-3 (200-2000명 미드마켓)**, 한국 본사 미드마켓 |
| 가격 | **시트당 월 35,000원~** (연 계약 협상, **공개 가격표에 "Custom"으로만 표기**). 시트 수 / 계약 기간 / 도메인 깊이로 협상. |
| 시트 한도 | 200시트+. 500시트 이상은 별도 할인 협상 (대량 할인 floor: 시트당 월 28,000원). |
| 포함 도메인 | Business 전체 + **한국 노무·세무 풀 깊이** (4대 보험, 근로기준법 워크플로우, 노무사 협업 정식, KISA 전자서명 — Phase 4, 국세청 ezTax — Phase 4). |
| AI/A2UI 한도 | A2UI 4도메인(PM/Comms/HR/문서) 완전 횡단. **자체 호스팅 옵션 (vLLM, 한국 리전)**. Phase 4 알파. |
| 통합/임포터 | Business 전체 + 커스텀 통합 (전용 엔지니어링 1회 포함), 데이터 웨어하우스 export. |
| 보안 | **SOC2 Type II 보유, K-ISMS (Phase 4), 망분리 제외**, SCIM 정식, DLP 정책 풀, 감사로그 무제한 보관, IP 화이트리스트, 세부 RBAC v2, 한국 리전 데이터 저장 보장. |
| 결제 방식 | **연 청구서 결제 (PO 기반)**. 부가세 별도. USD/JPY 옵션 (Phase 4 글로벌 알파, 일본 한국계 법인 한정). |
| 지원 | **전담 CSM**, 24/7 SLA, 도입 컨설팅 (1회 포함), 분기 임원 리뷰. |
| 마진 가정 | 매출총이익률 목표 **60%+** (자체 호스팅 시 50% 하회 허용). |

**가격 근거**: Slack Enterprise Grid 사용자당 월 $15 ≈ 21,000원(competitive-landscape.md). Enterprise floor 35,000원은 **Slack EG 대비 약 1.67배** — 단, Conflow는 **PM+Comms+HR+문서+A2UI 횡단을 한 시트로** 제공. Slack EG + Jira Premium + Workday + Flex 묶음 시 직원당 월 30-40만원 대비 **약 1/10**. product-vision.md Phase 3 종료 조건 "미드마켓 ACV 5,000만원+" 정렬: 200시트 × 21,000원 × 12개월 = 약 5,040만원 (연 결제 floor 시).

## 가격 비교 표 — 경쟁 대안 대비

직원당 월 비용 (KRW, 부가세 별도). 묶음 비용은 각 도구의 SMB 표준 플랜 기준 추정. **컨텍스트**: [positioning.md](../00-vision/positioning.md) 차별화 축 4 "마이그레이션 비용 0"의 가격 측 증명.

| 회사 규모 | Conflow Team (연) | Conflow Business (연) | Jira+Slack+Flex 묶음 | Linear+Slack 묶음 | Monday Pro | ClickUp Business |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 30명 | **10,000원** | 18,000원 | 약 60,000-80,000원 | 약 30,000-40,000원 | 약 24,000원 | 약 19,000원 |
| 80명 | 10,000원 | **18,000원** | 약 120,000-180,000원 | 약 40,000-60,000원 | 약 30,000원 | 약 24,000원 |
| 200명 | (권장 외) | 18,000원 (Business floor) | 약 200,000원+ | 약 60,000원+ | 약 36,000원 | 약 30,000원 |
| 500명 | (권장 외) | (Enterprise 권장) | 약 250,000-350,000원 | 약 80,000원+ (Slack EG) | 약 40,000원+ | 약 35,000원 |

**해석**:

- Conflow Team/Business는 **단일 도구로 PM+Comms+(HR+문서)** 제공이 가격 비교의 결정적 차이. Linear+Slack은 PM+Comms만, Monday/ClickUp은 보드 기반 자체조립.
- Jira+Slack+Flex 묶음은 jtbd.md Trigger 1의 30초 메시지 근거 (직원당 월 25만원 vs. Conflow 1.2-1.8만원).
- 500명 구간은 Conflow Enterprise (시트당 월 28,000-35,000원). Slack Enterprise Grid 단독($15) 대비 약 1.3-1.7배지만, 4도메인 합산으로는 1/10.
- 한국 SaaS 시세 위치: 카카오워크(5,000-9,900원), Flex(7,000-15,000원) 대비 Conflow Team은 **상위 25% 위치** — PM+Comms 통합 프리미엄으로 정당화.

## AI/A2UI 가격 모델

LLM 비용은 우리 가격의 가장 큰 변수다. Tier 내 포함 + over-cap 단가의 균형이 핵심.

### Tier별 AI 한도 (가설 v1)

| Tier | AI 메시지 한도 | 도메인 횡단 (A2UI) | over-cap 단가 (가설) | 자체 호스팅 |
| --- | --- | --- | --- | --- |
| Free | 워크스페이스당 월 50메시지 | 불가 | 차단 (Team 업그레이드 유도) | 불가 |
| Team | 시트당 월 500메시지 | **불가** (단일 도메인만) | 메시지당 50원 (over-cap) | 불가 |
| Business | 시트당 무제한 (워크스페이스 cap: 시트수 × 2,000메시지) | **가능** (PM↔Comms Phase 2, +HR Phase 3) | cap 초과 시 메시지당 30원 또는 협상 | 불가 |
| Enterprise | 무제한 | 4도메인 풀 횡단 (Phase 4) | 무제한 (자체 cap) | **vLLM 옵션 (한국 리전 보장)** |

### 한국 데이터 정책

- Phase 1-3: OpenAI gpt-4o-mini 기본 (글로벌 리전). Business 이상에서 데이터 사용 동의서 / 처리 위치 명시.
- Phase 4: **Enterprise는 한국 리전 / 자체 호스팅 옵션 보장**. K-ISMS 인증과 정렬.

**왜 도메인 횡단을 Business 이상으로 제한하는가**: 차별화 축 2를 Team 가격에 끼우면 ① LLM 비용으로 마진 폭사 ② Business 업그레이드 동기 소멸. A2UI는 **유료 전환과 expand의 가장 큰 무기**다 (jtbd.md COO-2, CEO-1).

## 할인·확장·다운그레이드 정책

### 연 결제 할인

- 표준: 월 가격 대비 **15-20% 할인** (Team 17%, Business 18%, Enterprise 협상).
- 미드마켓 다년 계약: 2년 약정 시 추가 5%, 3년 약정 시 추가 8%.

### 스타트업 할인 (Phase 1-2 land 가속)

- **시드/시리즈 A 한국 스타트업: Team/Business 50% 할인, 12개월** (Phase 1-2 한정).
- 자격: 누적 펀딩 50억원 이하, 직원 80명 이하, 한국 본사.
- 갱신 시 일반 가격 적용. 12개월 후 이탈률은 분기 GTM 리뷰 모니터링.

### 노무사·외부 협업자

- **노무사 외부 협업자 시트: 무료** (Business+). 단, 해당 노무사가 별도 회사의 메인 사용자로 활동 금지 (1 회사 1 외부 시트).
- 외부 컨설턴트·외주 디자이너: 게스트 시트 (시트당 월 5,000원, 자기 영역만 접근).

### 시트 추가·감소 정산

- **시트 추가**: 즉시 일할 계산 청구.
- **시트 감소**: 다음 결제 주기에 반영 (월 결제: 다음달, 연 결제: 다음 분기). 환불 없음.
- 다운그레이드 (Tier 하향): 도메인 데이터 보관 (HR/문서 read-only) **90일 유예**. 90일 후 자동 삭제 또는 export.

### 환불 정책

- 신규 가입 14일 무조건 환불.
- 연 결제 중도 해지: 사전 30일 안내 + 잔여 기간 비례 환불 (단, 스타트업 할인 적용 건 제외).

## 차별화를 깨는 가격 실수 (Anti-patterns)

영업·재무가 압력 받을 때 흔들리지 말아야 할 6개.

### 1. 도메인별 분리 가격 ("HR만 별도 1만원 더")

**왜 금지**: [jtbd.md](./jtbd.md) Big Job #2 즉시 깨짐. ICP-1 → ICP-2 자생 확장 시 HR을 켜는 결정이 "추가 결제 협상"으로 변질. 차별화 축 4 무력화.

### 2. "AI 무제한" 약속 (LLM 마진 폭사)

**왜 금지**: gpt-4o-mini 시세에서도 시트당 월 메시지 1만건 무제한이면 원가가 1만원을 넘는다. Team 가격(1.2만원)에서는 적자 구조. **Tier별 cap + over-cap 단가**로 관리한다.

### 3. Free Tier 30시트까지 무료

**왜 금지**: ICP-1 자격 기준 "직원당 월 1.5만원 지불 의향" 검증 실패. Phase 1 종료 조건(유료 워크스페이스 100개) 위협. **10시트 한도 유지**.

### 4. 한국 결제 수단 누락

**왜 금지**: 카드만 지원 시 ICP-1 세금계산서 요구사 이탈. 세금계산서만 지원 시 신용카드 결제 SaaS에 익숙한 시리즈 A 스타트업 이탈. 연 청구서 누락 시 ICP-3 협상 불가 (icp.md). **3가지 모두 Phase 1부터 지원**.

### 5. Enterprise 공개 가격표 게시

**왜 금지**: ICP-3은 연 계약 협상 시장. 공개 가격은 협상력 상실 + 경쟁사 가격 매칭을 부른다. **"Custom"만 표기, floor는 내부 기준**.

### 6. 미드마켓 시트 가격이 Slack Enterprise Grid 초과

**왜 금지**: Slack EG ≈ 시트당 월 21,000원 (사용자당 $15, competitive-landscape.md). Conflow Enterprise floor 35,000원은 1.67배 — **단, 4도메인 통합 가치로 정당화 가능**. 그러나 50,000원 초과 시 jtbd.md Trigger 1 ("Atlassian 가격 인상")의 대안 포지션이 무너진다. **floor 35,000원 / 대량 할인 28,000원 유지**.

## 가격 모델 재검토 트리거

[product-vision.md](../00-vision/product-vision.md) "변동 영역" 표의 가격 모델 행과 정렬. 분기 GTM 리뷰에서 다음 신호 점검.

| 신호 | 의미 | 검토 옵션 |
| --- | --- | --- |
| Free → 유료 전환율 < 10% (Phase 1 6개월 누적) | Free가 너무 관대하거나 Team 가치 약함 | Free 시트 한도 축소 (10→5), Team 무료체험 14일 추가 |
| Business 미드 (3-12개월 사용자) 이탈 > 20% | Business 가격이 ICP-2 가치 대비 비쌈, 또는 ICP-1 확장 시 HR 부족 | Business 가격 인하, HR Phase 3 빨리, Pro Tier 신설 (Team + A2UI) |
| 미드마켓 ACV 6개월 누적 < 3,000만원 | Enterprise floor가 시장 인내치 초과 | Enterprise floor 인하 (35,000→28,000), 도메인 부분 부킹 검토 (단, 원칙 1 위반 신중) |
| AI cap 도달율 < 30% (Team), > 80% (Business) | AI 한도 설계 오류 | Tier별 한도 재조정, over-cap 단가 조정 |
| 경쟁사(Linear, Notion, ClickUp)가 도메인 횡단 AI 가격 공개 | 차별화 축 2 동격화 | A2UI 가격 모델 재설계, Enterprise 자체 호스팅 무료화 |
| 한국 SaaS 시장 평균 시트 단가 변동 ±30% | 시장 시세 변화 (인플레이션, 카카오워크 가격 조정) | Tier 가격 전반 재조정 |

재검토 결과 가능한 변경 방향:

- **Usage-based 부분 도입**: AI 메시지 / 스토리지 / 외부 협업자 시트를 사용량 기반으로 일부 전환
- **Pro Tier 신설**: Team과 Business 사이 (예: 시트당 월 16,000원, A2UI 횡단만 추가)
- **도메인 부분 부킹 (신중)**: 원칙 1을 깨지 않는 선에서 "HR 활성화 fee" 형태 — 단, 시트 가격 인상이 아닌 일회성 활성화 비용

## 단계별 출시 (Phase ↔ 가격)

product-vision.md Phase 0→4와 정렬.

| Phase | 시점 | 출시 Tier | 가격 공개 범위 | 영업 모델 |
| --- | --- | --- | --- | --- |
| Phase 0 | 2026 H2 | Free + 알파 무료 (5-10개사) | 가격 페이지 없음, 알파 전원 무료 | 검증 인터뷰만 |
| Phase 1 | 2027 H1 | **Free / Team / Business** 출시 | Team/Business 공개. Enterprise는 "Custom, Contact Sales" | PLG 100% |
| Phase 2 | 2027 H2 – 2028 H1 | A2UI 정식 가격 (Business+) | A2UI cap / over-cap 단가 공개 (Business). Enterprise 여전히 비공개 | PLG 100% |
| Phase 3 | 2028 H2 – 2029 H1 | **Enterprise 가격 정식** (floor 시그널만) | 공개 페이지: "Starting at ₩35,000/user/month". 협상 비공개 | PLG:SLG = 50:50 |
| Phase 4 | 2029 H2 – 2030 | 한국 노무·세무 Enterprise 프리미엄 | 한국 노무 풀 깊이 / KISA / ezTax는 Enterprise 한정 — ACV 1억원+ 정렬 | SLG 주력 (미드마켓) |

### 각 Phase의 가격 결정

- **Phase 0**: 가격 결정 없음. 알파 무료 (5-10개사 12개월 무료 약속).
- **Phase 1**: Team 12,000원 / Business 22,000원 시작. 첫 100개 워크스페이스 데이터로 검증.
- **Phase 2**: A2UI cap 정식. Business 가격 ±10% 조정 여지 (검증 데이터 기반).
- **Phase 3**: Enterprise floor 35,000원 공개. 한국 노무 기본은 Business, 풀 깊이는 Enterprise.
- **Phase 4**: KISA 전자서명 / ezTax 출시와 함께 Enterprise ACV가 자연 인상 (시트당 가격 인상이 아니라 시트 수 × Tier 깊이로).

## 재무 모델 가정 (간단)

이 숫자는 모두 **가설 v1**. 검증은 [`03-roadmap/metrics.md`](../03-roadmap/metrics.md)에서.

### Phase 1 종료 (2027 H1 말)

- 유료 워크스페이스 **100개** (product-vision.md 종료 조건)
- 평균 시트 수 40명 (ICP-1 30-80명 중간)
- Tier 비중 가정: Team 80% / Business 20%
- 월 매출 계산:
  - Team: 80개 × 40시트 × 11,000원 (월/연 평균) = 약 3,520만원
  - Business: 20개 × 40시트 × 20,000원 = 약 1,600만원
  - **합계: 월 약 5,120만원, 연 ARR 약 6.1억원**

### Phase 3 종료 (2029 H1 말)

- 미드마켓 워크스페이스 **20개**, 평균 ACV 5,000만원 (product-vision.md)
  - 미드마켓 매출: 20 × 5,000만원 = **연 10억원**
- SMB 잔여 (Team + Business 누적): 600-800개 워크스페이스 추정
  - SMB 매출 추정: 700개 × 40시트 × 15,000원 × 12개월 ≈ **연 50.4억원**
- **Phase 3 종료 ARR 가설: 약 60억원**

### Phase 4 종료 (2030)

- 미드마켓 ACV 평균 1억원+ (product-vision.md, 한국 노무·세무 풀 깊이로 인상)
- 한국 IT SMB 유료 워크스페이스 **1,500개+**
- ARR 가설: 1,500개 × 40시트 × 평균 16,000원 × 12개월 ≈ 약 115억원 (SMB) + 미드마켓 40개 × 1억원 = **연 ARR 약 155억원**
- 이 숫자는 매우 거친 추정. SMB 평균 시트가 50명에 도달하면 ARR이 약 30% 상향.

**경고**: 위 숫자는 **가격 가정 × 시트 가정 × 전환율 가정의 3중 곱**이다. 어느 하나만 틀려도 ARR이 ±40% 변동. 6개월마다 metrics.md에서 보정.

## 결제 운영 (한국 시장 디테일)

### 결제 수단

- **카드 정기결제**: Phase 1부터. 토스페이먼츠 또는 이니시스 PG. Team/Business 표준.
- **세금계산서 발행 (수동/자동)**: Phase 1부터. 사업자등록번호 등록 후 매월 자동 발행. 부가세 10% 별도 표기.
- **연 청구서 (Invoice)**: Phase 1부터. Business 연 결제 + Enterprise 전용. PO 기반.
- **부가세**: 전 Tier 부가세 10% 별도. 결제 화면 / 청구서에 명확히 분리.

### 통화

- 기본: **KRW**.
- Enterprise USD/JPY: Phase 4 글로벌 알파 (일본/동남아 한국계 법인 한정). 영미권 직접 진출 시점까지 비공개.

### 환불 정책

- 신규 가입 14일 무조건 환불 (Team/Business).
- 연 결제 중도 해지: 사전 안내 후 비례 환불 (스타트업 50% 할인 적용 건은 제외).
- Enterprise: 계약서 조건 따름 (보통 환불 없음, 잔여 기간 서비스 제공).

### 영업·재무 워크플로우

- 카드 결제 실패 시: 3회 자동 재시도 → 7일 유예 → 다운그레이드 (Free 강등). 데이터는 90일 보관.
- 세금계산서 미수금: 30일 경과 시 채권 관리. 60일 경과 시 다운그레이드.
- Enterprise 연 청구서: PO 발행 → 30일 결제 조건 표준.

## 가격 변경 정책

이 문서는 **3개 트리거** 시 갱신한다.

1. **분기 GTM 리뷰**: 위 "가격 모델 재검토 트리거" 신호 점검. 신호 미발견 시 분기 갱신 생략 가능.

문서 책임자: 제품 전략 + 재무 + GTM 리드. 갱신 시 변경 이력을 본 파일 하단에 추가.
