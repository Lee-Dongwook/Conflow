## 6월 전략: "동작하는 3개가 더미 6개보다 낫다"

7월 출시를 위해 **모든 페이지를 완성하는 것이 아니라**, 핵심 루프를 실제로 동작하게 만드는 데 집중한다.

### MVP 핵심 루프

```
팀 생성 → 스프린트 설정 → 백로그 관리 → 보드에서 작업 → 허들 회의
→ AI 회의록 생성 → 블로커 감지 → 이번 주 뷰 자동 반영 → 회고
```

### 출시 시 제외 (v1.1+)

- DM (1:1 메시징)
- 허들 음성/영상 (WebRTC) — 텍스트 트랜스크립트 입력으로 대체
- 메트릭스 페이지 — 대시보드 내 기본 지표로 축소
- RAG 서비스 — 에이전트 LLM 모드로 커버

| 회원가입 플로우 완성 (Supabase email signup + 동의)         | FE+BE | P0       |
| 로그아웃 + 세션 관리 구현                                   | FE+BE | P0       |
| 프로필 수정 API 연결 (이름, 아바타)                         | FE+BE | P0       |
