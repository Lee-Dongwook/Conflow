# 환경설정 페이지 (내 계정) — 제품 분석 및 로드맵

## 현재 와이어프레임 구성

1. **프로필 카드** — 아바타, 이름, 이메일, 역할 뱃지, 프로필 수정 버튼, 인증 상태
2. **기본 정보** — 표시 언어, 타임존, 워크스페이스 가입일
3. **소속** — 팀 목록 + 역할 (멤버/참여)
4. **알림 (더미)** — 일간 요약 메일, 스프린트 시작 알림, 멘션 푸시 토글

---

## 우선순위별 로드맵

### Phase 1 — MVP 필수 (공개 전 완료)

| 항목                                          | 이유                                                    | 난이도    |
| --------------------------------------------- | ------------------------------------------------------- | --------- |
| "(더미)" 라벨 제거                            | UI에 표시되면 미완성 인상. 미구현이면 섹션 자체 제거    | 매우 낮음 |
| "아직 인증 없음" → "이메일 인증하기" CTA 버튼 | 수동적 상태 텍스트 대신 액션 버튼으로 의도된 설계 전달  | 낮음      |
| 프로필 수정 실제 동작                         | 버튼이 있는데 동작 안 하면 신뢰 즉시 하락               | 중간      |
| 다크모드 토글 연결                            | 개발자 타겟 테이블 스테이크. useTheme 훅 구현 완료 상태 | 낮음      |
| 로그아웃 + 모든 기기 로그아웃                 | 대학생 공용 PC/도서관 사용 환경 — 보안 기본 요구사항    | 낮음      |

### Phase 2 — 초기 성장 (팀 3~5개 확보 후)

| 항목                                                      | 이유                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| 상태 메시지 (커스텀 + 프리셋: "시험 기간", "발표 준비중") | 일상적 활성 사용 유도, 플랫폼 활성감                        |
| GitHub 프로필 링크                                        | 개발 스터디 타겟의 핵심 소셜 시그널. input 하나로 구현 가능 |
| 알림 토글 실제 연결                                       | 더미 제거 후 3~4개 옵션만 실제 동작하게                     |
| 수업 시간 DND (방해금지 스케줄)                           | 대학생 특화 pain point 직격                                 |

### Phase 3 — 스케일 (트랙션 확보 후)

| 항목                                         | 이유                     |
| -------------------------------------------- | ------------------------ |
| 연동 관리 (GitHub, Google Calendar, Discord) | 플랫폼 확장 플레이       |
| 데이터 내보내기 / 계정 삭제                  | 신뢰 구축, 규제 대응     |
| 팀별 세분화 알림 설정                        | 팀 3개 이상 소속 시 필요 |
| 키보드 단축키 커스텀                         | 파워 유저 기능           |

## 경쟁 분석 기반 갭

### 보안/인증 (Slack, Notion, Linear 공통)

- 비밀번호 변경 / 소셜 로그인 연결 관리
- 활성 세션 목록 + 원격 로그아웃
- 대학생 공유 기기 환경에서 필수

### 프로필 (Notion, Linear)

- 아바타 이니셜 자동 생성 (이미지 미업로드 시 이름 첫 글자 + 컬러 원)
- 상태 메시지
- GitHub/Discord 링크

### 알림 (Slack, Linear)

- 채널/프로젝트별 알림 규칙
- DND 스케줄 (수업 시간 뮤트)
- 현재 토글 3개는 너무 단순 — 최소 카테고리별 분리 필요
